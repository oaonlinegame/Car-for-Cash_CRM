📘 คู่มือการทำงานฉบับสมบูรณ์ V2: Reactive Flowchart

นี่คือผังงานที่ถูกปรับปรุงโดยเน้นขั้นตอนการประมวลผล Reactive ที่อยู่ใน gui.js อย่างชัดเจน

⚙️ Flowchart: การโหลดข้อมูลและการอัปเดต UI

เฟส 1: การดึงข้อมูล (Non-Reactive Fetch)

1. สั่งโหลดจาก App

app.js (ใน setup) เรียก LeadApp.loadAll()

↓ (สั่งการ)
2. ดึงข้อมูลดิบ

lead.js สั่ง AppDexie.lead.getAll() เพื่อดึงข้อมูลทั้งหมดจาก **IndexedDB**

เฟส 2: การอัปเดตหน่วยความจำ (The Trigger Point)

↓ (ส่งข้อมูลดิบกลับมา)
3. **จุดกระตุ้น (THE TRIGGER)** 🚨

lead.js ส่งข้อมูล 10,000 รายการไปที่ Store.setItems('Lead', items)

ภายใน store.js: ข้อมูลใหม่ถูกกำหนดค่าทับตัวแปร Reactive: **`Store.data.leadItems`**

เฟส 3: การประมวลผล UI (Reactive Processing)

↓ (Vue Reactivity System ทำงาน)
4. คำนวณการกรอง (Computed Property 1)

gui.js: **`AppState.filteredLeads`** ถูกปลุกให้ทำงาน

นำค่า **`Store.data.leadItems`** (รายการทั้งหมด) มา **กรอง (Filter)** ตามคำค้นหา AppState.searchQueryDebounced

ผลลัพธ์: **รายการทั้งหมดที่ถูกกรองแล้ว**

↓ (ผลลัพธ์การกรองเปลี่ยน)
5. คำนวณการแสดงหน้า (Computed Property 2)

gui.js: **`AppState.pagedLeads`** ถูกปลุกให้ทำงาน (เพราะเฝ้าดู `filteredLeads`)

นำผลลัพธ์จาก `filteredLeads` มา **แบ่งหน้า (Pagination)** หรือ **จัดกลุ่ม (Chunking)** 2 คอลัมน์

ผลลัพธ์: **รายการที่พร้อมแสดงในหน้าปัจจุบัน**

↓ (ค่าที่พร้อมแสดงผลเปลี่ยน)
6. การแสดงผลบนหน้าเว็บ (UI Rendering) 🖥️

index.html: Template ของ Vue จะทำงานใหม่

โดยใช้คำสั่งวนซ้ำ (`v-for` หรือ `v-virtual-scroll`) บนตัวแปร **`AppState.pagedLeads`** เท่านั้น

ทำให้ UI แสดงผลลัพธ์ที่ถูกต้องตามหน้าและคำค้นหา

---

🔑 สรุปความสัมพันธ์ของตัวแปรใน gui.js

การทำงานใน gui.js ถูกตั้งค่าไว้ในฟังก์ชัน **`AppGui.setupUIMainComputed()`** (ชื่อใหม่)

// gui.js (setupUIMainComputed)

// 1. **filteredLeads** (เฝ้าดู Store.data.leadItems)
AppState.filteredLeads = computed(() => {
    // ... ใช้ Store.data.leadItems
});

// 2. **pagedLeads** (เฝ้าดู AppState.filteredLeads)
AppState.pagedLeads = computed(() => {
    // ... ใช้ AppState.filteredLeads.value
});

นี่คือหลักฐานที่ยืนยันว่า **`pagedLeads`** คือผลลัพธ์สุดท้ายที่ถูกส่งไปใช้ใน Template ครับ
